# mediapipe 1.x is built against OpenCV 4; if pip installs opencv 5.x the
# pose model crashes the whole process (no traceback, window disappears).
# The upper bounds that enforce this live in constraints.txt, which run.bat
# passes with -c.

#       pip install "mediapipe==0.10.14" -c constraints.txt
#   * mediapipe>=1.0,<2   -> modern PoseLandmarker Tasks API (Python 3.10-3.14,
#     default; needs the model bundles in ./models).
mediapipe>=0.10.14,<2
